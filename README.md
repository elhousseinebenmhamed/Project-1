# موقع الثانوية التأهيلية المغرب العربي بمراكش

موقع ويب رسمي لمؤسسة تعليمية للثانوي التأهيلي، يهدف إلى توفير
معلومات شاملة للتلاميذ وأولياء الأمور والطاقم التربوي.

## 📋 نظرة عامة

يتضمن الموقع الصفحات التالية:

- **الرئيسية:** ترحيب، آخر الأخبار، روابط سريعة
- **عن المؤسسة:** التعريف، الرؤية، الأهداف
- **الطاقم التربوي والإداري:** الإدارة والأساتذة
- **الأنشطة الثقافية والرياضية:** الأندية والمسابقات
- **الاتصال:** العنوان، الهاتف، الخريطة، نموذج مراسلة

## 🛠️ التقنيات المستخدمة

- **HTML5** — هيكل الصفحات
- **CSS3** — التصميم (Flexbox، Grid)
- **JavaScript** — التفاعل والقائمة المتجاوبة
- **Git & GitHub** — إدارة الإصدارات
- **GitHub Pages** — الاستضافة
